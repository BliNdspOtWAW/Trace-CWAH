## Output Requirements

Select exactly one available action and provide its associated <subtask_id>. Use an active public task ID for task-specific actions, or null for task-independent exploration and probing. Grab/put actions must match the selected task's object and destination. Use the exact physical action text, including object IDs and parameters, from the available actions.

For physical actions, leave <message> empty and omit <communication_type> and <probe_target>.

For [send_message], use exactly one <communication_type> field: delegate with an exact active task ID, or probe with null subtask_id. A probe also requires exactly one <probe_target> field with one value from intent, capability, reliability, or information. Delegation must omit <probe_target>. Address the message to Bob in no more than 500 characters.

All protocol fields must be top-level siblings, with each required field appearing exactly once. Do not put protocol tags inside <cot> or <message>; ordinary object labels such as <apple> (375) are allowed in prose.
