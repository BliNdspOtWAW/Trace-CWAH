equivalence are independently established. The WAH candidate is downloaded from
`xavierpuigf/watch_and_help` and must not replace the existing CWAH dataset.

Binary datasets in this directory are local-only and ignored by Git.

See [DATA_AUDIT.md](DATA_AUDIT.md) for provenance, compatibility findings, and
the 100-episode inventory in [wah-manifest.jsonl](wah-manifest.jsonl).
